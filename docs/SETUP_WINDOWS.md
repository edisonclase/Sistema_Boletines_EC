# Configuración de Aula Nova en Windows

## 1. Propósito

Este documento describe el proceso para instalar y ejecutar Aula Nova en una computadora nueva con Windows 11.

## 2. Requisitos

- Windows 11 de 64 bits
- Git
- Python 3.12.7
- PostgreSQL 18
- wkhtmltopdf
- Visual Studio Code
- Acceso al repositorio
- Copia válida de la base de datos PostgreSQL
- Archivo `.env` local

## 3. Clonar o copiar el proyecto

Ubicación recomendada:

```text
F:\proyectos\AulaNova
